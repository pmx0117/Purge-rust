# Purge

Purge 是一款面向 Windows、Linux 和 macOS 的本地磁盘清理工具，帮助你查找应用缓存、闲置的开发产物、大文件和重复文件。支持中文界面、浅色与深色主题。

**[下载最新版](https://github.com/pmx0117/Purge-rust/releases/latest)**

## 功能

| 功能 | 可以做什么 |
| --- | --- |
| 应用缓存 | 查找浏览器、编辑器和常用应用的缓存，以及过期的临时文件 |
| 开发工具 | 检查包管理器缓存，以及你添加的开发项目中的依赖、虚拟环境和构建产物 |
| 大文件 | 查看下载、桌面、文档等用户文件夹中的大文件，按名称、类型和大小筛选排序 |
| 重复文件 | 在已扫描的大文件中查找内容相同的副本，帮助你选择多余的文件 |
| 应用卸载 | 查看已安装应用，切换卡片或列表布局，通过系统入口管理或卸载应用 |
| 清理历史 | 查看已移入回收站的项目数量、大小和操作记录 |
| 系统托盘 | 收起窗口后继续后台任务，通过托盘恢复窗口或退出 |

## 下载与安装

在 [下载页面](https://github.com/pmx0117/Purge-rust/releases/latest) 按系统和处理器选择安装包：

| 系统 | 文件名结尾 | 安装与启动 |
| --- | --- | --- |
| Windows 10 / 11 x64 | `windows-x64-setup.exe` | 双击安装，从开始菜单打开 Purge |
| Linux x64 | `linux-x64.tar.gz` | 解压后进入解压目录，运行 `./bin/purge` |
| Linux ARM64 | `linux-arm64.tar.gz` | 解压后进入解压目录，运行 `./bin/purge` |
| macOS Intel | `macos-x64.zip` | 解压后将 `Purge.app` 拖入“应用程序”文件夹 |
| macOS Apple Silicon | `macos-arm64.zip` | 解压后将 `Purge.app` 拖入“应用程序”文件夹 |

Windows 默认按当前用户安装，可选择安装目录和桌面快捷方式。更新时运行新版安装器覆盖安装即可；卸载应用会保留设置和清理历史。

Linux 安装包基于 Ubuntu 24.04 构建，需要兼容的系统库和 Vulkan 驱动，同时支持 Wayland 与 X11。

当前 Windows 安装器未做代码签名，macOS 版本尚未进行 Apple 公证。

## 如何使用

### 扫描与清理

1. 打开“概览”，点击“扫描全部”，或进入某个分类点击“重新扫描”。
2. 查看扫描结果，按需搜索、筛选和排序，选择准备清理的项目。
3. 点击“清理所选”；也可以在概览中点击“清理安全项目”。
4. 在确认窗口核对文件和路径，再点击“移入回收站”。清理前建议先关闭相关应用。
5. 在“清理历史”查看操作结果，需要恢复文件时前往系统回收站。

### 检查开发项目

进入“设置”，在“开发项目目录”中添加项目文件夹，再到“开发工具”重新扫描。可以添加其他磁盘上的项目目录。

“开发项目闲置时间”决定哪些项目产物会被列出。你也可以添加“排除目录”，让指定文件夹及其子目录不参与扫描和清理。修改扫描设置后需要重新扫描。

### 查找重复文件与管理应用

在“大文件”中完成扫描后，点击“查找重复”，再选择不需要的副本。同一组重复文件至少保留一份。

在“应用卸载”中查看应用信息，点击“管理应用”进入对应系统的管理入口。应用卸载不使用文件清理操作。

### 外观与后台运行

在“设置”中切换浅色或深色主题，也可以调整大文件阈值和启动扫描选项。

开启“最小化到托盘”后，最小化会收起窗口，后台任务继续运行，点击托盘可恢复窗口。Linux 桌面未提供系统托盘时使用普通最小化。关闭窗口会退出应用；正在执行清理时需等待完成后再退出。

## 使用提示

- 扫描范围包括常见缓存目录、用户文件夹和你添加的开发项目，不执行整盘遍历。
- 最近 24 小时内修改的临时文件和崩溃报告会被保留，这项规则不随开发项目闲置时间变化。
- 大文件和重复文件需要你主动选择；“安全”分类也不代表相关应用已经关闭。
- 清理会将文件移入系统回收站。只有清空系统回收站后，才会释放相应磁盘空间。

所有扫描与文件比较都在本机完成，不上传你的文件或扫描结果。设置和清理历史保存在本机。
